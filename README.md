# 🌟 EAIM-Education-Apps
**Emotion, Artscape, Interactive, Musicalization**

AI 기술과 예술을 융합하여 학생들의 사회정서학습(SEL)을 돕는 교과별 교육 애플리케이션 모음입니다. 35년 교육 경력의 전문가가 설계한 핵심 로직이 포함되어 있습니다.

## 🚀 포함된 앱 리스트
1. **국어 (Korean)**: 감정 시 시각화 및 공감 편지 쓰기
2. **뮤지컬 메이커 (Musical Maker)**: 학생 창작 뮤지컬 시나리오 및 구성 지원
3. **음악 콘서트 (Music Concert)**: 지능형 화성 분석 기반 합주 플랫폼
4. **과학 (Science)**: 과학적 원리와 예술의 융합 학습
5. **우주 (Space)**: 광활한 우주 테마를 통한 정서 확장
6. **체육 (Sports)**: 신체 활동과 감정 조절의 결합

## 🛠 기술 스택
- **Language**: HTML5, JavaScript (React)
- **Styling**: Tailwind CSS
- **AI Engine**: Google Gemini API
- **Design Methodology**: EAIM Framework (SEL 기반)
