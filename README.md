# 🌟 EAIM-Education-Apps
**Emotion, Artscape, Interactive, Musicalization**

AI 기술과 예술을 융합하여 학생들의 사회정서학습(SEL)을 돕는 교과별 교육 애플리케이션 모음입니다. 35년 교육 경력과 현장 내공을 보유한 전문가가 직접 설계한 핵심 교육 로직이 담겨 있습니다.

## 🚀 EAIM 스튜디오 핵심 앱 리스트 (6종)
1. **감정 시인 (korean.html)**: 내 마음을 아름다운 시와 그림으로 표현하는 국어 융합 도구
2. **생활 과학 톡 (science.html)**: 일상 속 과학 원리와 감성을 연결하는 이성과 감성의 추리
3. **태양계 오디세이 (space.html)**: 3D 공전·자전 뷰를 통해 드넓은 우주를 탐험하는 과학 도구
4. **천문대 관측소 (observatory.html)**: NASA 정밀 데이터 기반으로 별자리를 관측하고 일지를 기록하는 플랫폼
5. **뮤지컬 메이커 (musicalmaker.html)**: 기승전결 스토리 기반으로 학생 창작 뮤지컬 대본(오프닝/커튼콜 포함)을 구성하는 메이커
6. **비트 & 바스켓 (sports.html)**: 리듬과 신체 활동을 결합하여 학생들의 멘탈을 케어하는 스포츠 도구

## 🛠 기술 스택
- **Language**: HTML5, JavaScript (React)
- **Styling**: Tailwind CSS
- **AI Engine**: Google Gemini 2.5 Flash
- **Design Methodology**: EAIM Framework (예술 융합 SEL 기반)
